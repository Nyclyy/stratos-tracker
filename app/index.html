Aviation tools

Download for iPhone — Add to Home Screen

Stratos installs from the website; no App Store download is needed.

  1. Tap Open Stratos above to open the tracker in Safari.
  2. Tap Safari’s Share button.
  3. Scroll down and tap Add to Home Screen, then tap Add.

Download for Windows PC

Install Stratos as a desktop app with its own window. Public live aircraft tracking does not require Python to run in the background.

  1. Click Download for PC above to get Stratos-Setup.exe.
  2. Open the downloaded installer and follow the prompts.
  3. Launch Stratos from the Start menu.

Note: the PC download becomes available after the project is published to GitHub and a Windows release is built.

Install on Android

  1. Open Stratos in Chrome.
  2. Open the browser menu.
  3. Choose Install app or Add to Home screen.
Stratos is an independent project. Aircraft data is provided by third-party public ADS-B sources. Live coverage depends on provider availability. Not for real-world navigation.
